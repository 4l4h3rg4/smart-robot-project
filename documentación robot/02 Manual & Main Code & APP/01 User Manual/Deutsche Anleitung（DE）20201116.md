Linienfolgemodus

Kleben Sie das Isolierband auf den Boden, um eine Spur zu erstellen. Stellen Sie das Auto nun auf die Spur.

Wenn Sie die Taste 1 der Fernbedienung drücken, schaltet das Fahrzeug in den Linienfolgemodus und die Statusanzeige
leuchtet durchgehend grün. Der Wagen bewegt sich in diesem Modus entlang der Spur.

Hindernisvermeidungsmodus

Wenn Sie die Taste 2 der Fernbedienung drücken geht das Fahrzeug in den Hindernisvermeidungsmodus über. Die

Statusanzeige leuchtet durchgehen gelb. Das Fahrzeug fährt automatisch vorwärts, bis es auf Hindernisse triﬀt. Es wird
automatisch in eine Richtung ohne Hindernisse abbiegen, um seine Fahrt vortzusetzen.
