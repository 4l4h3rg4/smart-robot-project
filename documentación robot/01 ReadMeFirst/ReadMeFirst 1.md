Program FAQ
When learning the Tutorial, the IDE will be prompted with the following error "No such file or directory"
after clicking
upload.

"SSS": is the name of the library file you are missing.
Here is a much more convenient method to solve it.
1. Open the "Copy Me First" file in the current folder.

2. Select the extracted folder and copy it.

3. Right click "Arduino" ->"Properties"

4.Click "Open File Location".

5. Click "libraries" in the pop-up window to enter the folder, and then right-click to paste.

6. After pasting, click

again,

and then upload successfully.
